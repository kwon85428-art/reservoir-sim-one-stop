## 一、这是给谁做的

给**石油/能源背景、要亲眼看数值模拟每一步怎么咬合的人**——不需要再讲达西定律，需要的是一个跑得起来的透明闭环：数据从哪进、参数怎么调、不确定性怎么传到预测区间。

所以这个 skill 的写法是：

- **模拟器 240 行 numpy/scipy 裸写**，每个物理约定（迎风、井指数、CFL）都摊开可见，不装黑箱；
- **每个判据都配一个实测反例**（奇异系统 NaN 静默卡死、井项符号反压力倒挂、k 整体尺度不可辨识），从错误里长出来的纪律；
- **置信度是一等公民**：第 ⑤ 步直接给后验区间和 P10/P50/P90 预测带，不是事后补的误差棒。

它不替代商业模拟器，也不替代真实矿场数据拟合服务。它的定位是**油藏模拟的方法论透明化教学与 AI 产品验证探针**。

## 二、内容结构

### 第一层 · 模拟内核（scripts/sim_pipeline.py）

| 模块 | 核心 |
|---|---|
| **IMPES 求解器** | 隐式压力（稀疏直解）+ 显式饱和度（迎风 + CFL），Brooks-Corey 相渗，Peaceman 井指数 |
| **合成数据发生器** | lognormal 渗透率场 + 高渗条带（对比度 c），月度采样 + 高斯噪声 → `truth_monthly.csv` |
| **历史拟合** | 扫 c → 水率 RMSE U 形曲线 → `c_best` |
| **预测** | 注水量 ×1.5 制度变更，真值/拟合/盲三线对比 |
| **置信度节点** | χ² 似然 → 参数后验（1σ/95% 区间、ESS）→ 后验加权 P10/P50/P90 预测带 |

### 第二层 · 判据体系（references/method-and-pitfalls.md）★ 核心资产

| # | 判据 | 一句话 |
|---|---|---|
| 1 | **可辨识性** | 不可压缩+定率注采下 k 整体尺度不可辨识；可辨识的是非均质结构——历史拟合产品主打"调 k 倍数"即红灯 |
| 2 | **数据充分性** | `RMSE_min/σ ≤1.2` 数据榨干；`>2` 结构性失配，点估计不可信 |
| 3 | **预测区间** | 单线预测（无 P10–P90 带）= 缺 UQ，结论打对折 |
| 4 | **离散近似警示** | 后验 ESS<2 时区间只是候选点近似，无直接意义——节点会如实标注 |

> ⚠️ **诚实边界**：第 ⑤ 步是**剖面似然近似**（单参数、6 离散候选、其余参数固定），不是完整贝叶斯后验；生产级 UQ 用 MCMC / ES-MDA。本 skill 给的是方法论骨架与判据口径。

### 第三层 · 数据对账（references/data-checklist.md）

| 档 | 内容 |
|---|---|
| 合成字段 ↔ 真实矿场数据来源 | 每个合成参数对应什么测量、常见坑是什么 |
| 数据优先级 | 钱少先买什么：动态 > PVT > 特殊岩心 > 测井 > 地震 |
| 四问框架接口 | 求解器出身 / 校验规则 / 专业环节位置 / 断供风险 |

## 四、怎么用

### 会触发的场景

- **跑模拟**：合成数据跑模拟、油藏数值模拟、水驱、见水、含水率、注采制度
- **拟合与置信度**：历史拟合、可辨识性、置信区间、后验、P10P50P90、不确定性量化
- **AI 产品拆解**：验证油藏 AI 产品的拟合/预测逻辑、四问框架探针

### 不触发的场景（硬边界）

- 商业模拟器方案设计（Eclipse/CMG/tNavigator/HiSimPro 建模与方案优化）→ 转对应商业工具与油藏方案流程
- 真实矿场数据的历史拟合生产服务 → 转 `oilfield-data-analyst` / 数据治理流程
- 组分 / 热采 / 压裂 / 全隐式模拟需求 → 不激活（本 skill 只有黑油两相 toy）
- 油价/市场/炼化问题 → 转 `oil-expert`

## 五、边界与免责

1. **教学/验证级 toy**：不可压缩、无毛管压力、无重力、显式饱和度——数值结论仅在本合成体系内成立，外推到具体油藏需真实数据重跑；
2. **置信度是剖面似然近似**：单参数、离散候选、其余参数固定真值；ESS<2 时区间无直接意义（节点会自动标注）；
3. **本 skill 提供方法论骨架与判据口径，不构成任何油藏开发方案建议。**
