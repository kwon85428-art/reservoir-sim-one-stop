# 方法论与实测坑（引用本 skill 产出前必读）

## 物理约定

- **模型**：2D 油水两相 IMPES（隐式压力 + 显式饱和度），不可压缩，无毛管压力、无重力。
- **单位制**：场单位——k [mD]、长度 [ft]、粘度 [cp]、压力 [psi]、流量 [stb/day]。
  几何传导率 `T = 0.006328 · k_harm · A / d`（0.006328 是达西-场单位换算常数）。
- **井**：注水井定率源；生产井 BHP 约束，Peaceman 井指数
  `WI = 0.006328 · 2π · k · h / ln(re/rw)`，`re = 0.208·dx`，`rw = 0.328 ft`。
- **相渗**：Brooks-Corey 型幂律，`krw = S*², kro = (1-S*)²`，`S* = (S-Swi)/(1-Swi-Sor)`，Swi=0.15, Sor=0.20。
- **迎风**：面流动性取压力高侧（上游）；无毛管时上游 = 压力梯度方向。

## 三个实测坑（每个都让第一次跑全错）

### 坑①：奇异系统 → NaN 静默卡死
双定率井（注水 +Q、生产 −Q）时压力方程右端和为零、系数矩阵有常数零空间。
`spsolve` 返回 NaN + RuntimeWarning，若不把 warning 升级为 error，NaN 会污染饱和度、
`dt=NaN`、时间循环空转到步数上限——**不报错，只在结果里烂掉**。
处置：`warnings.filterwarnings("error", category=RuntimeWarning)`，或生产井用 BHP 约束打破零空间。

### 坑②：井项符号反 → 压力场倒挂
质量守恒约定 `Σ_faces w(p_i − p_j) = q_ext` 时，装配行 `A·p|_i = Σ w(p_j − p_i) = −q_ext`：
- 注入源 q_ext=+Q → `b[i] = −Q`（**负**）；
- 生产井 BHP：`q_ext = −wi·mobt·(p−pbh)` → 对角 `A[i,i] -= wi·mobt`，`b[i] -= wi·mobt·pbh`。
实测符号写反的症状：注入井压力低于生产井（水倒流堵死）或全场压力漂到负值（BHP 锚定失效）。
**验证锚点**：修好后 `p_inj > p_prd > pbh`，且 `qo+qw == q_inj`（稳态质量守恒）。

### 坑③：CFL 口径
显式饱和度的步长限制来自**水相 + 油相面通量之和**（总流度），只算水相会在见水前把 dt 放得过大。
且 x/y 面通量形状不同（(nx-1,ny) vs (nx,ny-1)），矢量累加时必须各用各的邻居切片，否则广播报错。

## 核心判据：渗透率整体尺度不可辨识

不可压缩 + 定率注采下，`k → k/m` 时压力场按 m 缩放、达西流速不变 → **饱和度路径与水率曲线完全不变**。
推论：
1. 历史拟合的可辨识方向是**非均质结构**（条带/河道/夹层分布），不是标量倍数——
   本 skill 的拟合旋钮因此选"条带对比度 c"而非"k 倍数"；
2. 任何历史拟合工具里"整体渗透率倍数"若显著变化仍报拟合改善，先怀疑它同时改了别的参数（如井指数/相渗端点）；
3. **AI 历史拟合产品拆解探针**：问它拟合旋钮是哪些、目标函数对旋钮的敏感性、静态不确定性怎么传到预测区间。
   三问答不上 → 大概率是产量外推器，不是模拟内核。

## 已知截断行为

高对比度条带（c≥10）使条带内通量增大、CFL 变小，`--t-end 2400` 时可能触到 `max_steps=12000`
上限提前截断（`run_meta.json` 里 `steps.truncated=true`）。截断会缩短拟合窗口——比对 RMSE 前先看各 c 的截断标记。
需要完整窗口就加大 `max_steps` 或减小 `--dx`。

## 置信度节点（第 ⑤ 步）判据

观测噪声 σ 已知时，拟合从"点估计"升级为"后验分布"，三个输出三条判据：

1. **参数后验区间**：`χ²(c) = N·(RMSE(c)/σ)²`，权重 `w ∝ exp(−Δχ²/2)`，
   在 log10(c) 上做加权 CDF 反插值得 1σ（15.9%/84.1%）与 95%（2.5%/97.5%）区间。
   `Δχ²=1` 与 `Δχ²=3.84` 两条阈值线（单参数）是区间宽度的可视化标尺。
   后验落在离散候选点上——ESS（有效样本数）小时区间是**离散近似**，加候选密度才收敛。
2. **数据充分性**：`RMSE_min/σ` 比值——
   `≤1.2` 已到噪声底（数据榨干，残差只剩噪声）；
   `1.2–2` 轻度结构失配（还有信号没被参数吸收）；
   `>2` 结构性失配（模型错了，调参数无用，点估计不可信）。
   注意 σ 必须是**真实计量噪声**：合成数据里它是已知的 0.02，真实矿场要先估计量误差再谈这条判据。
3. **预测区间**：用后验权重加权候选模型集合 → 含水率 P10/P50/P90 带。
   制度变更后的带宽度 = 静态不确定性向预测的传播量。**单线预测（无带）一律视为缺 UQ 的输出。**

诚实边界：这里的"后验"是**剖面似然近似**（单参数、6 个离散候选、其余参数全固定在真值），
不是完整贝叶斯后验——真实问题参数维度几十维、候选要 MCMC/集合平滑器（ES-MDA）。
本节点给的是**方法论骨架和判据口径**，不是生产级 UQ。
