# 储层模拟数据需求清单（合成数据 ↔ 真实数据的对应关系）

合成数据集各字段对应的真实矿场数据来源。拆解 AI 产品或评估数据资产时按此对账。

| 合成字段 | 真实对应 | 来源 | 常见坑 |
|---|---|---|---|
| 渗透率场（lognormal+条带） | 三维渗透率模型 | 测井解释 + 岩心标定 + 地质统计学 | 测井渗透率是井点真值、井间全是插值想象 |
| 条带对比度 c | 沉积相带/河道渗流差异 | 沉积微相研究 | 相控建模做得粗，条带位置本身就是拟合对象 |
| 孔隙度 φ=0.25 | 孔隙度模型 | 测井-岩心 | 与净毛比混淆 |
| Swi / Sor / 相渗曲线 | 特殊岩心分析 | 实验室（贵、慢、少） | 没做实验时靠类比借用——历史拟合的隐形自由度 |
| 注水量 Q（定率） | 注水井月度注入量 | 井口计量 | 分层注水量常靠嘴损折算，误差大 |
| 生产井 BHP | 井底流压/静压 | 压力计 / 井口折算 | 老井无永久压力计，折算误差大 |
| 月度 wc（+2% 噪声） | 月度油/气/水产量 | 井口计量 | 计量方式变更史、措施作业混在动态里，不清洗就拟合噪声 |
| 制度变更（×1.5） | 开发调整方案 | 油藏方案 | 预测可信度完全取决于拟合质量 |

## 数据优先级（钱少时先买什么）

1. **可靠的生产动态**（油/气/水月度 + 至少部分井的压力）——历史拟合的唯一靶子；
2. **PVT 实验**——决定模型类型（黑油 vs 组分）；
3. **相对渗透率/毛管压力**（特殊岩心）——决定见水规律，最贵也最常被省；
4. **测井解释的孔渗饱**——静态底座；
5. **地震构造**——决定井位，对模拟器只是边界。

## 对应四问框架（能源 AI 拆解）

- Q1 求解器是谁的 → 模拟器内核可本文档方法自建 toy 验证行为差异；
- Q2 校验规则库 → 有没有对计量口径/措施史的清洗规则；
- Q3 专业环节位置 → 历史拟合旋钮选的是什么（结构可辨识 vs 标量倍数）；
- Q4 断供风险 → 特殊岩心与 PVT 实验产能是数据链真瓶颈。
